What do I receive after purchase?

Each package includes the cog source, its database schema, an installation guide, a Supabase storage example, and the included license file.

What are the cogs built for?

Both cogs are built for Python bots using discord.py 2.3+ and use Supabase for their data layer.

Will it conflict with my bot’s existing commands?

All 16 included slash commands are grouped under /ewallet. The cog does not claim /economy, so it can sit alongside an existing economy feature and other namespaced packs.

Does Auto-Moderation need special bot permissions?

Yes. Enable the Message Content privileged intent in the Discord Developer Portal and invite the bot with Manage Messages so it can read and remove flagged messages.
